# FeatherScript

**A better way to build with AI in Roblox Studio.**

FeatherScript is an AI-powered Roblox Studio development tool designed to make building, scripting, and creating games easier and more enjoyable. It connects AI providers with Roblox Studio, allowing you to describe what you want and have the AI work directly on your project.

Whether you're creating an environment, designing a building, writing scripts, developing gameplay systems, or improving an existing project, FeatherScript aims to make the entire process smoother and more accessible.

Built with flexibility in mind, FeatherScript supports multiple AI providers and focuses on giving developers control over how they work. Its goal is simple: less time dealing with repetitive tasks, fewer limitations, and more time bringing ideas to life.

FeatherScript is actively being developed, with a focus on improving provider reliability, execution speed, creative tools, and the overall development experience.

**Built for Roblox creators. Made for bigger ideas.**
